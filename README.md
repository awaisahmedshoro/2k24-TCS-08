# SkyCast Weather Application

## Run in VS Code
1. Extract the ZIP and open the folder in VS Code.
2. Open `index.html` with Live Server, or directly in a browser.
3. Keep internet access enabled for live weather lookup.

## Six screens
1. Login (name, email and password)
2. Overview
3. Hourly forecast
4. 7-day forecast
5. Search city
6. Settings (Celsius/Fahrenheit and light/dark mode)

## Demo login
Enter any name, valid email format and password of at least 4 characters. Your name appears in the profile and welcome heading. This is a front-end demo only; it does not create or verify a real online account.

Weather lookup uses Open-Meteo. Forecast rows are illustrative projections based on current conditions.
